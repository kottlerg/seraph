## Summary
Each CPU's `PerCpuData` now holds the thread it runs (`current`), the address of its own entry (`this`) and its `CpuDiag` record (`diag`), so the kernel reaches its own CPU's thread, scheduler and per-CPU state with one GS- or `tp`-relative load instead of reading the CPU index and indexing a slab. Cross-CPU readers keep `scheduler_for(cpu)` and the scheduler's `current`.
